The owner supplied the following three PNG images on 5 November 2026. The originals are bundled in this folder and preserved byte-for-byte. They are approved for provisional use in pcHouseStore Web; visual refinement may happen later.

## Asset handling

- Do not overwrite or optimize the supplied originals in place.
- Do not stretch, skew, recolour, add effects, or crop the source files.
- If optimized web formats, favicon sizes or a refined wordmark are needed, generate separate derived files later and retain these originals.
- Render “PC House” as UI text beside the mark when a textual brand name is required; the supplied artwork is an icon/mark, not a readable wordmark.
- Keep a single canonical frontend asset path so the mark can be replaced centrally.
