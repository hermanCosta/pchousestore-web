# Design System — Initial Direction

**Status:** DRAFT

## Product direction

A clean, modern back-office application for a computer retail and technical service business.

## Layout

- Collapsible left navigation.
- Top bar with current company, user profile and contextual actions.
- Breadcrumbs for nested workflows.
- Responsive content area.
- Tables with search, filters, sorting and pagination.
- Consistent form layouts and confirmation dialogs.

## Visual principles

- Light theme as initial default.
- Neutral surfaces and restrained blue accent.
- Clear hierarchy and readable typography.
- Consistent spacing, radii, borders and focus states.
- Dense data tables balanced with generous form spacing.
- Status labels with both color and text.

## Accessibility

- Keyboard navigation.
- Visible focus indicators.
- Semantic controls and labels.
- Color is never the only signal.
- Adequate contrast.

## Pending

- Brand/logo assets and color palette.
- Mobile navigation behavior.
- Dashboard KPIs.
- Permission-dependent navigation.
- Exact component library.
